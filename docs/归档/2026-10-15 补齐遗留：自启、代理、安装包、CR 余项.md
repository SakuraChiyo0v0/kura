## 做了什么

| 项 | 改动 |
|-|-|
| 开机自启 | 设置页「登录 Windows 时自动启动」（默认关）。写 `HKCU\…\Run`，带 `--hidden` 启动只进托盘、不弹窗口。冒烟不碰注册表 |
| 出网代理 | 外网中继那条 https 链路读 `HTTPS_PROXY` / `NO_PROXY`（Node 24 自带的 `proxyEnv`）。局域网 http 链路不走代理。启动日志记一句走没走代理（只记主机，不记整串） |
| 安装包 | `npm run dist` → `release/Kura-Setup-<版本>.exe`（NSIS、装到当前用户、不要管理员、未签名）。asar 里只有 `dist/` 与 `package.json`，约 2.7 MB |
| 图标 | `scripts/make-icon.mjs` 按原托盘图的图形矢量重画，出 16–256 多尺寸 `icon.ico` 与 `tray.png`，不依赖图像库。窗口、任务栏、安装包都用它 |
| 终端尺寸 | 握手完成前报的尺寸会被丢掉 → 先记下、open 时补发（见下面坑 3） |
| CR 余项 | `ModulesView` 保存竞态、`FilesView` updater 里的副作用、几处轮询乱序（目录列表、传输、本机 WebDAV 状态）都加了「只认最后一次请求」 |
| 冒烟 | `KURA_SMOKE_EXE=release\win-unpacked\Kura.exe` 可对打包产物跑同一套冒烟 |

## 踩过的坑

### 1. Node 的 http 代理模式不让改 Host

以为 lan 链路也能顺手走代理。实测 `http.request` 带了 `proxyEnv` 的 Agent 后，Host 头和目标地址不一致会直接抛
`ERR_INVALID_ARG_VALUE: The property 'Host in options.headers' must match the request authority`
—— lan 模式恰恰是「拨 IP、发公网域名的 Host」。所以代理只接在 https（中继）上；https 走 CONNECT 隧道，Host 在隧道里，不受影响。
局域网本来也不该走公司代理，这个限制正好对得上。

### 2. electron-builder 解压后 rename 稳定 EPERM

以为是偶发、重试就好。实测连续两次都挂在 `rename win-unpacked.tmp → win-unpacked`，事后手动 rename 又成功 ——
是杀软在扫刚落地的 `electron.exe`。改成 `electronDist: node_modules/electron/dist`，直接复制 npm 已装好的那份，不再下载解压，之后一次过。

### 3. 「四个服务偶尔不出现」这次没复现，复现出来的是终端尺寸

连跑 10 次冒烟，「4 个服务卡片」那条每次都过；挂的是另一条「终端发送窗口尺寸」（2/10）。
原因：界面开标签后下一帧就报首个尺寸，这时 WebSocket 往往还在握手，`resize()` 见不是 OPEN 就直接 return；
之后窗口不变就再也不发，真 PTY 一直停在 80×24。改成记下最后一次尺寸、open 时补发，加了单测（旧代码上确认失败）。
「服务不出现」仍然**未复现、未定位**，这轮没为它改代码。

### 4. 手工装安装包时路径被吃掉反斜杠

在 Git Bash 里给 NSIS 传 `/D=C:\Users\…`，反斜杠被吃掉成 `C:Users…`（驱动器相对路径），装到了不知道哪里（全盘找过找不到），
只留下桌面 / 开始菜单快捷方式和 HKCU 卸载项。已按卸载项里的 GUID 和快捷方式的目标路径逐个确认后删掉。
之后改用 Node `spawnSync(…, { windowsVerbatimArguments: true })` 传参，装、卸都正常。
教训：给 Windows 程序传路径别经过 bash 的字符串拼接。

## 有意的取舍

- **不读 Windows 系统代理（IE 设置）**：Go 版也不读。要用就设环境变量。
- **没有代码签名**：首次运行 SmartScreen 会提示未知发布者。
- **卸载保留 `%APPDATA%\Kura`**：凭据、设置、模块都在那，误卸后重装能接着用。
- **图标沿用占位图的图形**，只是变清晰、补齐尺寸；要换正式设计改 `make-icon.mjs` 里的 `shade()` 重跑。
- **Sakura UI 的等宽字体 token、StatCard 尺寸**：是上游组件库的缺口，Kura 已在应用层兜住（`--kura-font-mono`、收小一档），没去改 Sakura。
