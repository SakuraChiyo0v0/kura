# 「挂到文件夹」一切换就弹「保存失败」

日期 2026-10-15。用户在模块页点「挂到文件夹」，右下角连弹两条「保存失败：挂载目录要写成绝对路径：（空）」。
点两次弹两条，看起来像竞态，其实是**必然**。

## 一、根因：同一份 `folder`，界面与主进程各按各的意思读

- 界面（`ModulesView.tsx`）：`folder` 是**父目录**，挂载点是它下面的 `KuraNAS` 子目录，
  还配了个系统目录选择器。
- 主进程（`modules.ts` 的 `validateFolder`）：把 `folder` 当**挂载点本身**，要求 `^[A-Za-z]:\\`。

切形态走的是 `saveSettings({ ...settings, mode: 'folder' })`，把 `mountDefaults.folder`（空串）
一起送去保存 → `validateFolder('')` 直接抛错。**还没轮到用户选目录就先报了错。**

冒烟没抓到，是因为它只断言「切过去后出现父目录字段」，不看有没有弹错。
真机测试 `modules.real.test.ts` 也没抓到 —— 它传的是完整挂载点 `D:\...\KuraNAS`，
恰好符合主进程那套「folder 就是挂载点」的理解，于是两边拧着的语义一次都没撞上。

## 二、顺带三处同源的问题

1. **提示语用词是错的**：空 folder 不是「保存失败」，是「还差一个必填项」。真把路径填全是能存上的。
2. **切到文件夹模式后「挂载」按钮永远点不亮**：`ready` 要求 `Boolean(settings.folder)`，
   而 folder 在存上之前一直是空；加上输入框只有 `onBlur` 才保存，只有走目录选择器才救得回来。
3. **`D:\` 这种父目录**（选盘根）会被 `^[A-Za-z]:\\` 拒绝，因为去掉末尾分隔符后剩 `D:`。

## 三、改法（用户选定）

- **空 folder 允许存**：`validateFolder('')` 返回 `''`，不再抛。「还没选」这件事挪到**挂载时**拦
  （`mountTarget` 抛「还没有选挂载到哪个文件夹」）。保存失败与「还没填完」是两回事，不该共用一个提示。
- **界面把 toast 换成行内提示**：父目录字段下加一条 `.kura-form__hint`（warning 色 + 图标），
  「还没选文件夹，选好才能挂载」；挂载按钮继续 disabled。缺必填项说在字段旁，不弹全局 toast。
- **挂载点的拼接只留一份**：设置里存**父目录**，挂载点由 `folderTarget()` 拼。
  这个函数放在新文件 `src/shared/mount.ts`（零依赖）—— 主进程与渲染层都要读，
  但渲染层不能从 `main/modules.ts` 引（那会把 `node:child_process` 带进打包产物）。
- `validateFolder` 额外放行盘根 `D:`（`/^[A-Za-z]:$/`），但 `D:sub` 这种「盘符相对」仍然拒绝。

## 四、踩的坑

**「一次点击换两条 toast」≠ 竞态。** 我第一反应是去查 `saveSeq` 那套防连点的逻辑
（`ModulesView` 里确实有，注释也写着「保存也会被连点」）。但 `FluidSegmented` 的实现是
`onChange={() => r(e.value)}` —— 原生 radio，每次点击只触发一次。两次点击两条，是**每次点击各错一次**，
不是同一次错两遍。**先怀疑语义，别先怀疑时序**：如果每次点击都稳定错，那多半是逻辑本身在错。

**渲染层不能引主进程的模块。** 我第一版直接 `import { folderLeaf } from '../main/modules.js'`，
typecheck 照样过（`.d.ts` 阶段看不出运行时依赖），但打包时会把 main 那一串 `node:` 模块拉进渲染层。
共享的纯函数放 `src/shared/`（`labels.ts` 就是这么做的），别图省事从 main 引。

**冒烟里的假通过。** 断言「挂载按钮灰着」时我写了
`...?.disabled !== false` —— 元素找不到时 `undefined !== false` 是 `true`，**永远通过**。
改成先把按钮找出来、必须真找到（找不到就给个 `没找到` 哨兵），再判 disabled。
同理，断言「没弹 toast」一开始数了屏幕上所有 toast，被前面几步残留的成功提示误判；
改成只数含「保存失败」的那种。

## 五、验证

`npm run check` 全绿：typecheck 干净 · 331 单测 · 冒烟 **55/55**（新增一条覆盖本 bug）· 重启 **7/7**。

新增的冒烟断言三条一起看：切到文件夹模式后**不出现「保存失败」toast**、
**出现行内提示**、**真有一个被禁用的挂载按钮**（不能靠 `every` 落空假通过）。
截图 `v0.3-模块-文件夹模式.png` 里能看到提示与置灰的按钮。

**没做**：真机跑 folder 模式（要 `KURA_REAL_RCLONE=1`、联网、占盘符）。真机测试的 folder 用例
已跟着改成传父目录，但这一轮没在真手上跑。
